# TIVISION — téléchargements

TIVISION est un lecteur IPTV pour Android TV / Google TV, téléphones Android et Windows : TV en direct avec guide des programmes, films et séries, recherche, recommandations, profils.

**TIVISION ne fournit aucune chaîne ni aucun contenu.** Tu ajoutes tes propres sources (playlist M3U, guide XMLTV) que tu as le droit d'utiliser.

## Android TV / Google TV / Fire TV (avec Downloader)

1. Installe l'app **Downloader** (by AFTVnews) depuis le Play Store de la TV.
2. Ouvre Downloader et tape cette adresse :
   ```
   https://github.com/youssefelmajdoul/tivision-releases/releases/latest/download/tivision.apk
   ```
3. Installe quand Downloader le propose. Si la TV le demande, autorise Downloader à **installer des applications inconnues**.

Cette adresse donne toujours la dernière version : pour mettre à jour, refais la même chose, l'installation se fait par-dessus sans perdre tes réglages.

## Téléphone Android

Ouvre la page [Releases](https://github.com/youssefelmajdoul/tivision-releases/releases/latest) sur le téléphone et télécharge `tivision.apk` (ou `TIVISION-…-android-arm64-v8a.apk`, plus léger, pour la plupart des téléphones récents).

## Windows 10 / 11

Télécharge `TIVISION-…-windows-x64.zip` dans [Releases](https://github.com/youssefelmajdoul/tivision-releases/releases/latest), décompresse-le et lance `tivision.exe`. Windows peut afficher « Windows a protégé votre ordinateur » (l'app n'est pas signée) : *Informations complémentaires › Exécuter quand même*.

## Quel fichier choisir ?

| Fichier | Pour |
|---|---|
| `tivision.apk` | Tout appareil Android, **recommandé pour les TV** (contient toutes les architectures) |
| `…-android-arm64-v8a.apk` | Téléphones et boîtiers récents (64 bits), plus léger |
| `…-android-armeabi-v7a.apk` | Anciens appareils et beaucoup de TV en 32 bits |
| `…-windows-x64.zip` | PC Windows |
